
# Windows Themes Library

Used to browse, search and view the planned Windows desktop theme library. It includes several built-in themes organized by categories, and supports switching between light and dark themes.

## Features

### Theme Browsing
- Includes 437 curated Windows themes
- Browse by 16 categories:
  - Games
  - Anime & Cartoon
  - Military & Camo
  - Cars & Transportation
  - Everyday Objects
  - Animals
  - Flowers & Plants
  - Ocean & Beach
  - Space & Universe
  - Seasons & Holidays
  - Mountains & Landscapes
  - Weather & Skies
  - Cities & Architecture
  - Travel Landmarks
  - Abstract Art
  - Other
- Sidebar displays all categories and the number of themes in each
- "All Themes" view for browsing the entire collection
- Theme cards show cover image, name, publisher, rating, wallpaper count, and free/paid badge
- In the "All Themes" view, cards also show their category label

### Search & Sorting
- Real-time search by theme name, publisher, and description
- Search box supports one-click clearing
- Multiple sorting options:
  - Top rated
  - Most rated
  - Newest
  - Name A→Z
- Empty-state message when no matching themes are found

### Theme Details
- Click a theme card to open the detail panel
- Displays theme icon, name, publisher, product ID, category, rating, rating count, price, and release date
- Shows a hero preview image and up to 8 additional preview images
- Displays the full theme description
- Shows info cards for wallpaper count, rating, rating count, price, release date, and product ID
- Supports opening the theme in Microsoft Store
- Supports copying the product ID with success/failure toast feedback

### Image Viewing
- Click any preview image in the detail panel to open a full-screen image viewer
- Click to close the full-screen viewer
- Press `Esc` to close the detail panel and image viewer

### Personalization
- Light/dark theme switching
- Light and dark modes use different colors, shadows, and background effects
- Chinese / English UI language switching
- After switching language, navigation, titles, search box, sorting options, detail info, and toast messages update accordingly
- English mode can display English descriptions for themes

### Interaction Experience
- Theme cards lift and show shadows on hover
- Staggered entrance animation for theme cards
- Search box bottom highlight on focus
- Language dropdown menu with current language indicator
- Toast notifications for operation feedback
- Keyboard shortcuts:
  - `/` focuses the search box
  - `Esc` closes overlays

### Responsive Layout
- Desktop layout uses a sidebar plus main content area
- Mobile layout automatically switches to a stacked layout
- Theme grid adapts to screen width
- Detail panel and image viewer adapt to small screens
